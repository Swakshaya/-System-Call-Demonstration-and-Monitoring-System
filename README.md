
Project Title: SysGuard – Linux System Monitoring and Management System

Project Description:

SysGuard is a Linux-based system monitoring and management application developed using C and Linux system programming concepts. The main purpose of the project is to provide users with a simple and comfortable interface to monitor important system activities without requiring them to remember or manually execute multiple Linux commands.
The application provides a menu-driven interface through which users can access different system-related features such as System Overview, Process Manager, Memory Monitor, File Explorer, IPC Center, Signal Monitor, Thread Monitor, and System Logs.
The System Overview displays basic information about the Linux operating system, kernel, architecture, hostname, current user, and process ID. The Process Manager allows users to view running processes, all processes, their own processes, and current process information. Process creation and execution are demonstrated using Linux mechanisms such as fork(), exec(), and waitpid().
The Memory Monitor retrieves memory-related information from the Linux /proc filesystem and demonstrates dynamic memory mapping using mmap() and munmap(). The File Explorer allows users to view files, obtain file information, create files, write data, and read file contents using Linux file system calls such as open(), read(), write(), and close().
The IPC Center demonstrates communication between processes using pipes. The Signal Monitor demonstrates asynchronous event handling using POSIX signals such as SIGUSR1. The Thread Monitor demonstrates multithreading and synchronization using POSIX threads and mutexes. System Logs maintain records of important operations performed within SysGuard.
Overall, SysGuard combines multiple Operating Systems and System Programming concepts into a single user-friendly Linux application. It provides practical demonstrations of processes, inter-process communication, signals, memory management, file management, threads, synchronization, and system information while presenting them through a simple menu-driven interface.
